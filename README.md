# GIFT LINK - web application

_JavaScript/TypeScript Full Stack web application (Demo/Exercise)_

Technologies: MongoDB (a NoSQL database for data storage), React.js, TypeScript, JavaScript, Docker and containers.

## Project Overview

The GiftLink application connects users who wish to give away household items they no longer need with users who enjoy recycling and prefer to find free household items to match their tastes rather than purchasing new ones.

From the user interface perspective, the application contain a home page, a listings page, a navigation bar, a search function, an item details page, a registration page, a login page, and an editable profile page.

## Technology & Architecture

- Front-end: React components. The Gifts Website
- Backend: APIs and endpoints in the back end and integrate those APIs into respective components on the front end.
  - Gifts Services
  - Sentiment Analyzer Service

## Development Commands

Run these commands from the repository root:

```bash
# Lint all workspaces
npm run lint

# Lint and auto-fix issues
npm run lint:fix

# Format all files with Prettier
npm run format

# Check formatting without changing files
npm run format:check

# Run TypeScript checks across workspaces
npm run typecheck

# Run tests across workspaces
npm run test

# Run tests with coverage across workspaces
npm run test:coverage

# Build all workspaces
npm run build

# Full validation (lint + format check + typecheck + coverage)
npm run check
```
